How to download all attachments from Gmail at once

Gmail gives you a download button for one email at a time. If you need the attachments from dozens of emails (invoices, receipts, contracts, reports), clicking through each message is slow. Here is how to save all attachments from a Gmail search in one go.

The built-in options and their limits

Inside a single email with several attachments, Gmail offers a “download all attachments” button. It only covers that one message. Google Takeout can export your whole mailbox, but you get everything, not just the files you need, and it can take hours or days.

Download all attachments from many emails with InboxZip

  1. Install InboxZip from the Chrome Web Store.
  2. Search in Gmail for the emails you want, for example has:attachment from:accounting.
  3. Open InboxZip next to Gmail and choose the file types: PDF, images or other.
  4. Press Download ZIP. InboxZip fetches the attachments with your own Gmail session and builds one ZIP on your computer.

InboxZip exports the results page you are looking at, up to 3 exports per day.

Gmail search filters that help

  • has:attachment only emails with files attached
  • filename:pdf only PDFs (or filename:xlsx, filename:jpg)
  • from:name@example.com one sender
  • after:2026/01/01 before:2026/02/01 a date range
  • larger:5M only big files

Combine them: has:attachment filename:pdf from:accounting after:2026/01/01 finds every PDF from one sender this year.

Download only the PDFs from Gmail

Search with filename:pdf or just tick PDF in InboxZip before you start. The archive then contains PDFs only, with duplicate names numbered so nothing is overwritten.

Is it private?

Yes. The files go from Gmail to your browser and the ZIP is built locally. There is no sign-in, no Gmail API and no upload of your emails or attachments to us.
