Como baixar todos os anexos do Gmail de uma vez

O Gmail oferece um botão de download para um e-mail por vez. Se você precisa dos anexos de dezenas de e-mails (notas fiscais, recibos, contratos, relatórios), abrir mensagem por mensagem é lento. Veja como salvar todos os anexos de uma busca do Gmail de uma só vez.

As opções nativas e seus limites

Dentro de um e-mail com vários anexos, o Gmail mostra um botão para baixar todos os anexos. Ele vale só para aquela mensagem. O Google Takeout exporta a caixa de entrada inteira, mas você recebe tudo, não só os arquivos de que precisa, e pode levar horas ou dias.

Baixar todos os anexos de vários e-mails com o InboxZip

  1. Instale o InboxZip na Chrome Web Store.
  2. Pesquise no Gmail os e-mails que quer, por exemplo has:attachment from:financeiro.
  3. Abra o InboxZip ao lado do Gmail e escolha os tipos de arquivo: PDF, imagens ou outros.
  4. Clique em Download ZIP. O InboxZip busca os anexos com a sua própria sessão do Gmail e cria um ZIP no seu computador.

O InboxZip exporta a página de resultados que você está vendo, até 3 exportações por dia.

Filtros de busca do Gmail que ajudam

  • has:attachment só e-mails com arquivos anexados
  • filename:pdf só PDFs (ou filename:xlsx, filename:jpg)
  • from:nome@example.com um remetente
  • after:2026/01/01 before:2026/02/01 um intervalo de datas
  • larger:5M só arquivos grandes

Combine: has:attachment filename:pdf from:financeiro after:2026/01/01 encontra todos os PDFs de um remetente neste ano.

Baixar só os PDFs do Gmail

Pesquise com filename:pdf ou marque PDF no InboxZip antes de começar. O arquivo terá só PDFs, e nomes repetidos recebem número para nada ser sobrescrito.

É privado?

Sim. Os arquivos vão do Gmail para o seu navegador e o ZIP é criado localmente. Sem login, sem API do Gmail e sem enviar seus e-mails ou anexos para nós.
