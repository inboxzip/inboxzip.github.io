Как скачать все вложения из Gmail сразу

В Gmail кнопка скачивания работает только для одного письма. Если нужны вложения из десятков писем (счета, чеки, договоры, отчёты), открывать каждое долго. Вот как сохранить все вложения из результатов поиска Gmail за один раз.

Встроенные способы и их ограничения

Внутри одного письма с несколькими вложениями Gmail показывает кнопку «Скачать все вложения». Она действует только для этого письма. Google Takeout выгружает весь почтовый ящик, но вы получаете всё подряд, а не нужные файлы, и это может занять часы или дни.

Скачать все вложения из многих писем с InboxZip

  1. Установите InboxZip из Chrome Web Store.
  2. Найдите письма в Gmail, например has:attachment from:бухгалтерия.
  3. Откройте InboxZip рядом с Gmail и выберите типы файлов: PDF, изображения или другие.
  4. Нажмите Download ZIP. InboxZip получает вложения через вашу собственную сессию Gmail и собирает один ZIP на вашем компьютере.

InboxZip выгружает открытую страницу результатов, до 3 экспортов в день.

Полезные фильтры поиска Gmail

  • has:attachment только письма с вложениями
  • filename:pdf только PDF (или filename:xlsx, filename:jpg)
  • from:name@example.com один отправитель
  • after:2026/01/01 before:2026/02/01 диапазон дат
  • larger:5M только крупные файлы

Фильтры можно сочетать: has:attachment filename:pdf from:бухгалтерия after:2026/01/01 найдёт все PDF от одного отправителя за этот год.

Скачать из Gmail только PDF

Ищите с filename:pdf или просто выберите PDF в InboxZip перед началом. В архиве будут только PDF, а одинаковые имена получат номера, чтобы ничего не перезаписалось.

Это безопасно для приватности?

Да. Файлы идут из Gmail в ваш браузер, а ZIP собирается локально. Без входа, без Gmail API и без загрузки ваших писем или вложений к нам.
