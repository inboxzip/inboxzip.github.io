Comment télécharger toutes les pièces jointes Gmail d’un coup

Gmail propose un bouton de téléchargement pour un seul e-mail à la fois. Si vous avez besoin des pièces jointes de dizaines d’e-mails (factures, reçus, contrats, rapports), ouvrir chaque message est long. Voici comment enregistrer toutes les pièces jointes d’une recherche Gmail en une fois.

Ajouter InboxZip à Chrome Gratuit

Les options intégrées et leurs limites

Dans un e-mail contenant plusieurs pièces jointes, Gmail propose un bouton pour tout télécharger. Il ne concerne que ce message. Google Takeout exporte toute votre boîte mail, mais vous obtenez tout, pas seulement les fichiers voulus, et cela peut prendre des heures, voire des jours.

Télécharger les pièces jointes de nombreux e-mails avec InboxZip

  1. Installez InboxZip depuis le Chrome Web Store.
  2. Recherchez dans Gmail les e-mails voulus, par exemple has:attachment from:comptabilite.
  3. Ouvrez InboxZip à côté de Gmail et choisissez les types de fichiers : PDF, images ou autres.
  4. Cliquez sur Download ZIP. InboxZip récupère les pièces jointes avec votre propre session Gmail et crée un ZIP sur votre ordinateur.

InboxZip exporte la page de résultats affichée, jusqu’à 3 exports par jour.

Filtres de recherche Gmail utiles

  • has:attachment uniquement les e-mails avec pièce jointe
  • filename:pdf uniquement les PDF (ou filename:xlsx, filename:jpg)
  • from:nom@example.com un expéditeur
  • after:2026/01/01 before:2026/02/01 une période
  • larger:5M uniquement les gros fichiers

Combinez-les : has:attachment filename:pdf from:comptabilite after:2026/01/01 trouve tous les PDF d’un expéditeur cette année.

Télécharger uniquement les PDF depuis Gmail

Recherchez avec filename:pdf ou cochez PDF dans InboxZip avant de commencer. L’archive ne contient alors que des PDF ; les noms identiques sont numérotés pour que rien ne soit écrasé.

Est-ce confidentiel ?

Oui. Les fichiers vont de Gmail à votre navigateur et le ZIP est créé en local. Pas de connexion, pas d’API Gmail, et vos e-mails et pièces jointes ne sont jamais envoyés chez nous.
